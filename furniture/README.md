# Ассеты мебели

Нарезка из `/home/vlad/DeepSeekHome2/pic_v2/furniture`.

## Структура

- `bags/` — 20 сумок, рюкзаков и кейсов;
- `chests/` — 20 сундуков;
- `closets/` — 20 шкафов и шкафчиков;
- `crates/` — 20 ящиков;
- `manifest.json` — источник, строка/колонка листа, размеры и путь каждого ассета;
- `_contact-*.png` — контактные листы для просмотра на тёмном фоне.

Все 80 ассетов — PNG с прозрачным фоном, обрезаны по содержимому.
Максимальный размер — 512 px по большей стороне. Исходная сетка 4×5,
границы ячеек взяты по белым промежуткам между предметами.

Ассеты пока не привязаны ни к одной книге. Скрипт нарезки:
`scripts/prepare_furniture_assets.py`.
