# AI-скиллы Quest/2

Готовые скиллы для ИИ-агента. Каждый скилл указывает, какой инструмент запускать
и как читать отчёт. Скиллы не меняют пакет автоматически: сначала отчёт, потом
решение.

- `quest-validate` — схема и семантика;
- `quest-graph` — граф и достижимость;
- `quest-simulate` — прохождение по seed;
- `quest-diff` — сравнение двух пакетов;
- `quest-convert` — одноразовая конвертация `quest/1 → quest/2`.
