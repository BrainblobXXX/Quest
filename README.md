# QUEST-166 — каркас движка текстовых квестов

Монитор на системном блоке с ЭЛТ-экраном: BIOS-заставка, библиотека игр, игровой экран.
Собрано по [MVP.md](MVP.md), §7–8.

## Запуск

Подробные инструкции по добавлению книг и иллюстраций — в [GAMES.md](GAMES.md).

```bash
npm install
npm run dev     # http://127.0.0.1:3100
npm run build   # продакшн-сборка (нужна для деплоя)
npm start       # standalone-сервер, порт 3000 или $PORT
```

Игры читаются прямо из `games/` в рантайме: сервер отдаёт файлы пакета, браузер
разбирает `story.md` и `game.yaml`. Сборки JSON нет — правка книги видна после
обновления страницы, а проблемы разбора показываются в интерфейсе.
Детали — в [GAMES.md](GAMES.md), §0.

## Что уже работает

- BIOS-заставка с проверкой памяти, пропускается кликом или клавишей;
- библиотека: две демо-игры, отметка продолжения, переключатель звука;
- игровой экран: строка состояния (глава + инвентарь), текст, нумерованные выборы;
- выборы с условием (`has_item`), взятие предметов (`take`), концовки;
- иллюстрации сцен: поле `image` в манифесте, кадр до 60% высоты, вписан целиком;
- клик по иллюстрации открывает её на весь экран (Esc или клик по фону — закрыть);
- на телефоне широкие иллюстрации кадрируются по центру и занимают больше экрана; полный кадр всегда доступен по клику;
- линейный переход `next` и бросок кубика `roll`/`outcomes`;
- автосейв в `localStorage` после каждой сцены;
- сброс прогресса (кнопка POWER и «СБРОСИТЬ ПРОГРЕСС») обнуляет прохождение, не перезагружая страницу;
- три физические кнопки на корпусе: «ИГРА», «БИБЛИОТЕКА» и «НАСТРОЙКИ» с защёлкой и паузой;
- корпус: питание, LEDs, FDD, CD-ROM, вентиляция, шильдик;
- звук: гул ЭЛТ, щелчки, писк загрузки (стартует после первого действия);
- клавиатура: ↑/↓ — выбор варианта (подсвечивается), Enter — подтвердить, цифры — выбрать сразу, Esc — в библиотеку.
- в библиотеке: ↑/↓ — переход по книгам, Enter — открыть, цифра — открыть сразу;
- в настройках: ↑/↓ — выбор пункта, Enter — включить/выключить, ←/→ — громкость;

## Структура

```text
app/                 Next.js: layout, страница, стили
components/          корпус, кнопки, экраны
lib/                 движок, условия, хранение, звук, разбор пакета (parse.ts)
games/               пакеты игр: game.yaml, story.md, items.yaml, ассеты
app/api/games/       отдача пакетов браузеру (список и файлы)
test/                проверки движка
```

## Деплой на ONREZA

Репозиторий `BrainblobXXX/Quest`, ветка `main`, корень проекта — этот каталог (файл
`package.json` лежит в корне репозитория).

| Настройка | Значение |
|---|---|
| Framework | Next.js (определяется автоматически) |
| Install command | `npm install` |
| Build command | `npm run build` |
| Start command | `node .next/standalone/server.js` |
| Node.js | 20.9+ (лучше 22) |
| Output directory | оставить пустым |
| Environment variables | не нужны |
| Порт | платформа передаёт `PORT`, сервер его слушает |

Почему именно так:

- игры не собираются вовсе: `games/` читается в рантайме через `/api/games/*`;
- `postbuild` копирует `games/`, `public/` и `.next/static/` внутрь `.next/standalone/`.
  Без этого на хостинге не будет ни стилей, ни пакетов игр: Next.js standalone их не
  копирует сам;
- `next.config.ts` включает `output: 'standalone'`;
- `npm start` запускает standalone-сервер, а не `next start` с жёстким портом.

Локальная проверка прод-сборки:

```bash
npm run build
PORT=3120 npm start        # http://127.0.0.1:3120
```
