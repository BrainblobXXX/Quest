# Библиотека иллюстраций контейнеров

Задача: один набор контейнеров, который подходит всем книгам — от фэнтези и хоррора до современности, Fallout и sci-fi.

## 1. Принцип

Контейнер в иллюстрации — это не «сундук вообще», а комбинация:

- **тип** — сундук, шкаф, ящик, сумка, сейф;
- **материал** — дерево, металл, картон, пластик, ткань, кожа;
- **эпоха/стиль** — фэнтези, современный, постапокалипсис, sci-fi;
- **состояние** — закрыт, открыт, пуст, заперт, сломан;
- **размер** — маленький, средний, большой.

Поэтому библиотека должна состоять из **базовых силуэтов + слоёв состояния**, а не из одной картинки на каждое упоминание.

## 3. Приоритет для первой партии

Чтобы покрыть большинство сцен, достаточно **12–16 базовых типов**:

1. деревянный сундук;
2. деревянный/армейский ящик;
3. картонная коробка;
4. платяной/кухонный шкаф;
5. стенной шкафчик;
6. металлический locker;
7. тумбочка;
8. комод;
9. письменный стол с ящиками;
10. книжная полка/стеллаж;
11. сейф;
12. дорожная сумка;
13. рюкзак;
14. мешок;
15. корзина;
16. чемодан/кофр.

Второй эшелон: бочка, футляр, инструментальный ящик, аптечный шкафчик, холодильник, тайник, кошелёк, труп/одежда.

## 4. Какие состояния нужны

Для каждого типа — минимум:

- **закрыт**;
- **открыт**;
- **пуст**;
- **заперт**;
- **сломан/вскрыт** — для силового вскрытия.

Дополнительно:

- **ловушка/опасность** — для чемодана с бомбой, шкафчика-ловушки;
- **засыпан/завален** — для тайников и старых кладовых;
- **разграблен** — для повторных посещений;
- **с содержимым** — лучше отдельными слоями, а не baked-in.

## 5. Стилевые варианты

Не нужно рисовать все типы во всех эпохах. Достаточно:

- **фэнтези/средневековье:** дерево, железо, кожа, сундуки, бочки, мешки;
- **современность:** картон, пластик, металл, сейфы, чемоданы, бытовая техника;
- **постапокалипсис:** ржавчина, брезент, армейские ящики, повреждённые сейфы;
- **sci-fi:** гладкий металл, пластик, контейнеры, панели, автоматические дверцы.

Универсальное ядро — дерево/металл/картон/ткань — кросс-жанровое.

## 6. Технические требования

- единый ракурс **3/4 сверху**;
- единое освещение;
- прозрачный фон;
- читаемый силуэт уже на **48–64 px**;
- без текста и логотипов на самом объекте;
- содержимое — отдельные предметы/слои;
- имя файла:

```text
containers/<type>/<material>/<state>.png
```

Примеры:

```text
containers/chest/wood/closed.png
containers/chest/wood/open_empty.png
containers/cabinet/modern/open.png
containers/safe/metal/locked.png
containers/suitcase/leather/broken.png
```

Метаданные:

```json
{
  "type": "chest",
  "material": "wood",
  "era": "fantasy",
  "size": "medium",
  "state": "open",
  "tags": ["locked", "quest"]
}
```

## 7. Что покрывает библиотека

- «открыть/обыскать» — шкафы, ящики, сумки, сейфы;
- «заперто/нужен ключ» — сундуки, сейфы, locker;
- «ловушка» — чемодан, коробка, шкафчик;
- «много отсеков» — комод, стол, кофр, шкаф;
- «обыск тела» — труп/одежда/карман;
- «пусто» — открытые пустые варианты;
- «ключ/код» — сейф, шкатулка, кошелёк, тайник.

Одна универсальная библиотека из **16 базовых контейнеров × 3–5 состояний** закроет большинство книг; редкие типы можно добавлять по мере появления.
