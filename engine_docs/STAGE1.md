# Этап 1 — общий UI-фундамент

Статус: выполнен.
Цель: убрать дублирование кубиков и клавиатуры, ввести единый `InteractionHost`,
не меняя формат книг и механические формулы.

## 1. Границы

Входит:

- общий компонент грани кубика;
- общий слой клавиатурных обработчиков панелей;
- `InteractionHost` для выбора проверки/ставки/боя;
- удаление локальных копий pips и `keydown`;
- smoke всех книг.

Не входит:

- `quest/2`;
- чистый reducer;
- миграции сейвов;
- изменение формул проверок/боя;
- переписывание `GameScreen` целиком.

## 2. Общий кубик

Требования:

- значения 1–6 — точками;
- значения больше 6 — числом;
- одинаковая разметка pips во всех панелях;
- поддержка дополнительного CSS-класса для конкретной панели;
- доступный `aria-label`;
- сценический кубик и боевые кубики используют один компонент.

Файл: `components/screens/Dice.tsx`.

## 3. Общий keyboard-слой

Требования:

- один хук для `window.keydown` в capture-фазе;
- обработчик возвращает `true`, если событие обработано;
- при `true` хук сам делает `preventDefault` и `stopPropagation`;
- автоматическая очистка слушателя;
- панели не дублируют `useEffect` с `addEventListener`.

Файл: `lib/usePanelKeys.ts`.

## 4. InteractionHost

Требования:

- принимает текущую сцену и состояние;
- выбирает один интерактивный блок по приоритету:
  бой → проверка → ставка;
- магазин и нижние действия сцены пока остаются в `GameScreen`;
- не знает id книги;
- не меняет приоритеты, зафиксированные в `ARCHITECTURE.md`;
- передаёт колбэки без изменений.

Файл: `components/screens/InteractionHost.tsx`.
