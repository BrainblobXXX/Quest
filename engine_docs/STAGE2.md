# Этап 2 — чистое ядро и состояние

Статус: выполнен.
Формат книг не менялся.

## 1. Что вынесено

### Случайность

`lib/rng.ts`:

- `Rng` — единый тип источника случайности;
- `createRng(seed)` — детерминированный mulberry32 для тестов;
- `rollDie`, `roll2d6`, `parseDice`, `rollFormula`.

Движок принимает `rng` последним аргументом:

- `newState(game, rng)`;
- `goToScene`, `choose`, `useCode`;
- `advance`, `roll`;
- эффекты `statRoll`.

Панели проверок, ставок и боев используют общие `rollDie`/`roll2d6`/
`rollFormula`, а не собственные генераторы.

### Действия

`lib/actions.ts`:

```ts
applyAction(game, state, action, rng) -> GameState | null
```

Действия:

- `choose`;
- `advance` (включая результат броска);
- `back`;
- `code`;
- `gamble`;
- `check` (включая списание морали);
- `buy`;
- `combat-win`.

`app/page.tsx` больше не считает мораль, деньги, покупки и переходы боя —
он только вызывает `applyAction`, сохраняет состояние и проигрывает звук.

### Версия состояния и миграции

`GameState.version`; актуальная версия — `STATE_VERSION = 2`.

`lib/migrations.ts`:

- нормализует старые журналы `knownCodes`/`gamblesDone`;
- переносит известные исправления Zombie Blood из `page.tsx` в миграцию;
- старые сейвы без версии получают версию 2;
- новые сейвы создаются сразу версией 2.

### Книжные ветки

- `repairSceneItems` удалён из `app/page.tsx` и живёт в миграции;
- `scene.key === 'create'` и `creation_points` удалены из `GameScreen`;
- счётчик сцены теперь данные (поле поддерживается парсером, но к существующим
  книгам не применялось):

```yaml
counter:
  stat: creation_points
  max: 10
  label: ОСТАЛОСЬ ОЧКОВ
```

### Боевой контракт

`lib/combat.ts`:

- `CombatMode = pool | contest | rpg`;
- `combatMode(game, combat)` определяет режим по данным, а не по флагам UI;
- `combatEnemies(combat)` — единый список врагов;
- `resolvePoolRound`, `resolveContestRound`, `resolveRpgRound` — чистые
  резолверы раундов с общим RNG;
- `applyPoolDamage` — общее распределение урона.

`GameScreen` больше не вычисляет `contestCombat`/`falloutCombat`;
`InteractionHost` получает режим из контракта. Все три панели вызывают
соответствующий чистый резолвер, оставляя у себя только анимацию и разметку.
