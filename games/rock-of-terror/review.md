## Проверка проходимости (кратчайший путь)

Поиск в пространстве состояний (сцена, известные коды, флаг `lame`) с ограничением кодов подсказками книги даёт: минимальный путь к §70 со знанием имени (`witch_name`) — **690 минут**, из них 630 до проверки §3. При трактовке (а) проверка видит 630 (≤660), час подъёма прибавляется после и даёт 690; порог 12 часов (720) не срабатывает, §100 достижим. Без ограничения кодов подсказками панель «КОДЫ» позволяет сокращать путь произвольно (код применяется из любой численной сцены) — это свойство формата, а не книги.

Запас: 690 из 720 минут, то есть победа возможна, но путь почти оптимален. Если игрок выбирает более длинную ветку, его ловит либо §3 (11 ч → §52), либо `timeout` (12 ч).

Победный путь (проверен по эффектам `game.yaml`): `1 → 66 → 86 → 41 → 87 → 20 → 64 → 10 → 59 → 90 → 56 → 56_knock → 6 → 43 → 57 → 14 → 29 → 32 → 33 → 53 → 65 → 17 → 98 → 81 → 93 → 11 → 28 → 85 → 8 → 88 → 75 → 27 → 19 → 44 → 3 → 3_plateau → 79 → 70 → 100`. Время: 630 до §3, 690 после подъёма; §56_knock видит ровно 240 (не больше) → §6; коды: `anna` (§27→19), `old_woman` (§33→53), `mirror` (§53→65), `dream_death` (§11→28), `witch_name` (§70→100).
